## 异常分析（仍是 P1 待办）

### char_zhao 长 THINK content 截断（3 次发生）

Phase 1 中 char_zhao 在 tick=4 / 9 / 10 都因 THINK content 超 max_tokens 触发 fallback DO_NOTHING。
- 都是 INTP 角色长篇内心独白被 v4-pro reasoning + content 双重消耗 token 预算
- length-aware retry 扩到 5625 tokens 仍未恢复（5625 也填满）
- fallback DO_NOTHING 是合法 action，killer test 仍通过

**P1 修复方案候选**：
1. `CharacterAction.content` 加 `max_length=500` 而非 2000（强制 LLM 简洁）
2. System prompt 加"content 不超过 80 字"约束
3. INTP/ISFJ 类思考型角色单独路由到更高 max_tokens（e.g. 4000）

### Phase 2 retry 率较高（10+ retries across 5 ticks）

后期角色历史/感知积累，prompt 更复杂；v4-pro reasoning 占用更多 budget。属于已知现象，P1 prompt 优化可缓解。
