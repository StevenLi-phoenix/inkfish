## 设计决策

### `_fix_truncated_json` 改进（vs mirofish）

mirofish 原版用简单计数法（`count('{') - count('}')`），无法区分字符串内的括号。INKFISH 版改用状态机：
- `in_string` flag 跟踪是否在字符串内
- `\\` 处理跳过 escape 序列（防止 `\"` 触发 flag 翻转）
- `stack` 存放未配对的 `{`/`[`，LIFO 顺序闭合
- 已配对的 JSON 走不到 stack pop 分支，idempotent 性质保持

### target 规则

| ActionType | target |
|---|---|
| SPEAK / MOVE_TO / REACT | 必须非空（strip 后非空） |
| THINK / DO_NOTHING | 必须为 None |
| ACT | 可有可无 |

### P0 triggers_interaction 限制

`triggers_interaction=True` 仅对 SPEAK 有效。P1 互动 budget 接入后在此处扩展规则。

## 实施过程中的修复

1. **mypy `BroadException` 警告**：`parse_action_json` 中 `except Exception` 改为带注释的宽捕获（Pydantic 可能抛 `ValidationError` 或 `TypeError`），mypy strict 下无警告。
2. **空字符串 target 的边界**：`_REQUIRES_TARGET` 规则检查 `not t or not t.strip()`，覆盖 `target=""` 和 `target="   "` 两种 LLM 输出。
3. **whitespace-only mood fallback**：`fallback_do_nothing` 中 `mood.strip()` 确保全空白字符串也回退到 `"neutral"`。
