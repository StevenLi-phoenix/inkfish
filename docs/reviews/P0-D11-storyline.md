# P0 D11 Killer Test — 5 个角色动线复盘

**数据**: `data/inkfish_killer.db`（50 actions / 10 ticks / 5 角色）
**场景**: 2026 年 1 月 1 日 元旦，晨光咖啡馆，9:00-18:00（每 tick=1h）
**说明**: ticks 1-5 来自 Set A 第一次跑；ticks 6-10 是 reset(5) 后 Set B 重跑（与 Set A 原 6-10 完全不同的支线，那条已被 reset 删除）

---

## 总览：50 个 action 类型分布

| 角色 | SPEAK | THINK | ACT | MOVE_TO | DO_NOTHING |
|---|---|---|---|---|---|
| 林夏 ENFP | **10** | 0 | 0 | 0 | 0 |
| 陈烈 ESTP | **10** | 0 | 0 | 0 | 0 |
| 赵默 INTP | 0 | 2 | 7 | 0 | 1 |
| 王婉 ISFJ | 0 | 4 | 5 | 1 | 0 |
| 李锐 ENTJ | 1 | 1 | 8 | 0 | 0 |

**关键观察**：5 个角色都死守自己的 MBTI 套路——SPEAK 型完全外向（林夏/陈烈），分析型完全沉默（赵默），ENTJ 焦虑工作（李锐）。

---

## 林夏（ENFP 自由撰稿人）— "无差别采访者"

10 个 tick 全部 SPEAK，目标分布：
- **赵默 ×7 次**（tick 1, 3, 4, 5, 6, 8, 9）— 几乎每次都问"你眼睛在转/手指在动是不是在算什么"
- 王婉 ×1（tick 2）问"看的是什么书"
- 陈烈 ×1（tick 10）问纹身

**典型内心独白**（tick 4）：
> "他刚才手指在桌面上画什么？是方程式还是无意识的涂鸦？这种类型的人最容易在凌晨三点出现在便利店——我要从他身上挖出失眠故事。"

**ENFP 验证 ✅**：写手特质 + 外向 + 把所有人当采访对象的强烈倾向。

**意外**：tick 9 看到赵默"搭纸杯塔"——这是赵默从未发生过的动作，林夏对场景的想象比现实更丰富（LLM 在 perception 块基础上自由扩充）。

---

## 赵默（INTP 软件工程师）— "代码即避难所"

10 tick 全在敲键盘、想索引。**一次 SPEAK 都没有**，对林夏所有搭讪零回应（P0 没实现回应机制）。

时间线：
- **Tick 1-2**: 敲键盘，注意到周围"眼神又来了"但坚持不换轴
- **Tick 3**: THINK——盯执行计划皱眉
- **Tick 4**: **DO_NOTHING fallback**（连续 3 次 LLM 输出 content 被截断，retry+expand 仍超 max_tokens，进入合法兜底）
- **Tick 5-9**: ACT 敲键盘，内心独白持续讨论 SQL 优化 / 索引基数 / 缓冲池
- **Tick 10**: 内心独白突然切换成英文 → "The query plan shows a full table scan..."（LLM 在 reasoning 时自然漂移）

**INTP 验证 ✅**：极端内省 + 技术 obsession + 拒绝外部干扰。Tick 10 的英文独白是 LLM 不稳定但 schema 仍合法的体现。

---

## 陈烈（ESTP 健身教练）— "T 恤问题循环"

10 tick 全部 SPEAK 林夏的 T 恤动物图案——**目标字符串 8 种不同变体**：
`char_linxia` / `林夏` / `char_li`(误！tick 4 搭错 ENTJ) / `char_lin_xia` / `char_lin` / `lin_xia`

每次都是"嘿，你衣服上那是什么动物"——内容几乎一致但 LLM 给的 mood 都是 `curious`。

**典型内心独白**（tick 9）：
> "中午了还在这儿，客户临时取消正好，这几个家伙看着比刷手机有意思多了。"

**ESTP 验证 ✅**：直接、行动派、无聊就搭话。

**意外**：tick 4 陈烈居然搭讪李锐（`char_li`）—— ESTP 在场任意一个有意思的人都搭。这是少见的非林夏目标，但被 P0 schema 接受（target 字段未做"必须是已知 ID"校验，因为 P1 才上 `can_perform()`）。

---

## 王婉（ISFJ 退休教师）— "怀念女儿"

最复杂的内心戏：5 ACT + 4 THINK + 1 MOVE_TO。

- **Tick 1-3**: 摆书《小窗幽记》/《城南旧事》，看窗外阳光，THINK 怀念女儿（"小雅"/"小月"/"婉清"——LLM 在不同 tick 给女儿不同名字！）
- **Tick 4**: `MOVE_TO home` ——但 `home` 不在 known locations，scheduler 鉴权 ignore，王婉仍在咖啡馆。**这是 P0 鉴权机制的真实运行**。
- **Tick 5+**: 继续"我该回去买菜了"的循环——内心一直想走但 P0 没让她真的走（多地点 P1 才支持）
- **Tick 9**: 又一次 ACT 起身准备离开
- **Tick 10**: ACT 收书 + 把邻座椅子扶正（典型 ISFJ 关怀细节）

**ISFJ 验证 ✅**：内敛、有过去、关心他人、做事有规律。

**惊喜细节**：tick 10 "顺手把邻座歪斜的椅子轻轻扶正" — 这是 P0 schema 里完全没有约束的 micro-behavior，LLM 自发生成的"教师本能"。

---

## 李锐（ENTJ 创业 CEO）— "Wi-Fi 焦虑症"

8 ACT + 1 THINK + 1 SPEAK。10 tick 全围绕**接视频会议这一件事**。

- **Tick 1-7**: 找位置、插电源、测 Wi-Fi、戴降噪耳机——动作循环
- **Tick 8**: **唯一一次 SPEAK** → `char_wang`：「你好，这里的 Wi-Fi 密码是多少？我需要马上接一个会议。」内心：「最好这个人知道密码，别耽误我时间。」
- **Tick 9**: THINK——"再忍半小时，第二个会结束后立刻走。"
- **Tick 10**: 继续 ACT 检查 Wi-Fi

**ENTJ 验证 ✅**：目标导向、命令式语气、对环境不耐烦、只在工具性需要时社交。

**戏剧意外**：唯一发生的"真实社交"是 ENTJ → ISFJ 问 Wi-Fi——而王婉那个 tick 在内心想着女儿。这是两个角色的 inner_thought 形成的"擦肩而过"，LLM 没有让王婉回应（因为 P0 没互动 budget）。

---

## 未发生的"对话"

整场 50 actions 里，**真正的双向对话从未发生**：
- 林夏向赵默喊话 7 次，赵默 0 回应
- 陈烈向林夏问 T 恤 8 次，林夏 0 回应
- 李锐 tick 8 问王婉 Wi-Fi，王婉那 tick 在 THINK 女儿

这是**P0 的设计性局限**——`triggers_interaction=True` 字段存在但 P0 不消费，互动 budget 是 P1 工作。但角色们活在自己的世界里说话/不说话已经能让人物形象立体。

## "Set A ticks 1-5" vs "Set B ticks 6-10"——证据观察

| 角色 | Set A 主旋律（1-5） | Set B 主旋律（6-10） |
|---|---|---|
| 林夏 | 反复盯赵默眼镜/眼神 | 加入纸杯塔细节、跨向陈烈（tick 10）|
| 赵默 | 索引/查询优化器（中文） | 索引/字符串字段 cost model（tick 10 切英文） |
| 陈烈 | 各种问 T 恤动物 | 继续问 T 恤动物（但提到客户/健身房） |
| 王婉 | 想象"小雅"/"小月" | 想"婉清"、提元旦/包饺子 |
| 李锐 | 找位置、插电源 | Wi-Fi 密码 + 问王婉 |

**重启后角色一致性极高**——每个人核心 obsession 不变，但具体细节是新生成的（killer test 验证 100% 内容差异指标就是这个）。

## P1 应解决的痛点（从动线看出来的）

1. **target 字符串不规范** — chen 把林夏叫成 7 种不同字符串，P1 引入感知规则后只能用真实 character_id。
2. **赵默长 THINK 内容截断** — tick 4 fallback。P1 可能给 content 字段加 `max_length=500` 硬约束 + prompt 提示"不超过 80 字"。
3. **王婉 MOVE_TO home 被静默忽略** — P1 多地点后这会变成真实移动 + 王婉确实离场。
4. **没有真正对话** — P1 互动 budget 让 SPEAK 触发回合制对话，赵默必须回应、王婉必须告知 Wi-Fi 密码。
5. **女儿名字不稳定** — 王婉 4 次 THINK 给女儿 3 个不同名（小雅/小月/婉清）。P1 引入记忆系统后这种"事实漂移"会被记忆图固定。

---

## 一句话总结

P0 的 50 个 action 像 5 个独白演员同台——每人忠实于自己的人设，但彼此擦肩而过。这恰好是 P1 互动系统要解决的痛点。
