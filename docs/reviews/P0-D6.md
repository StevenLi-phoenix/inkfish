## 关键决策落地

- **行为差异化在文本中显式表达**——例如 char_zhao 的 personality 含「不擅打断他人、倾向沉默」，char_chen 含「随机搭讪陌生人、急于行动」。这让 D11 killer test 的 persona 一致性检查有可观测的方差。
- **行字符串内的 `"` 用 `「」` corner brackets** 避免 JSON 字符串嵌套引号问题。
- **seed_world() 在写入前 reset(-1)**——保证 killer test 每次从字节相同种子启动。

## 实施过程中的修复

1. **JSON syntax error**：seed JSON 中嵌套 `"`（如 `"随机搭讪陌生人"`）破坏 JSON 结构。修复：9 处改为 `「」`。
2. **背景字数不足**：char_lin (350)、char_chen (343)、char_li (344) 起初 < 400。补充具体细节句。
3. **Ruff 10 处**：E501 行长 / UP017 datetime.UTC / UP037 quoted hint / F401 unused import / I001 排序——自动修复。
