## 关键决策落地

- **Composite PK**：CharacterRow / LocationRow 都用 `(id, tick_id)` 复合主键，验证：插入同 `id` 不同 `tick_id` 两行共存；重复 `(id, tick_id)` 抛 IntegrityError。
- **WAL 模式**：通过 `@event.listens_for(Engine, "connect")` 注册，对 `sqlite:///` URL 触发 `PRAGMA journal_mode=WAL; synchronous=NORMAL; foreign_keys=ON`。`test_wal_pragma_applied_to_file_db` 用 tmp_path 文件 DB 验证 `PRAGMA journal_mode` 返回 `wal`。
- **JSON 列**：`CharacterRow.routine`, `LocationRow.{present_characters,connected_to}` 用 SQLAlchemy `JSON` 类型，round-trip 测试通过。
- **UTC datetime**：用 Python 3.12 `datetime.UTC` 常量。
- **LLMLogRow.attempt**：补一个 attempt 字段（计划里没明确，subagent 主动加上以记录 retry 次数）—— 合理扩展，留给 D5 使用。
