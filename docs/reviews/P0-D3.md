## 实施过程中的修复

1. **DetachedInstanceError on debug logs**：write 方法 commit 后再读 ORM 字段会 detach。修复：commit 前先 capture 字段值用于 logging。
2. **DetachedInstanceError on read returns**：read 方法返回 ORM 对象后 session 关闭导致 detach。**根因**：`expire_on_commit=True` 默认。修复：`make_session_factory` 加 `expire_on_commit=False`——短生命周期 session 的正确模式。
3. **mypy `attr-defined` on `result.rowcount`**：去掉 debug log 中冗余的 rowcount 引用。
