## 实施过程中的修复

1. **B008 noqa**: ruff B008 flags `Depends()` in function defaults (standard FastAPI pattern). 按项目惯例（参见 `cli.py`）在每个 `Depends()` 调用后加 `# noqa: B008`。
2. **Import sort**: simulation.py 的 import 排序有小问题，整体重写修复。
3. **Test cleanup**: test 文件中的未使用 import 和未使用变量（`repo`）清理。
4. **`seeded_client` fixture**: 不依赖 CLI — 直接用 `seed_loader + SnapshotManager.save_snapshot(tick_id=0)` 注入 tick-0 快照，与 test_tick_scheduler.py 的模式一致。

## 关键设计决策

- **P0 同步模式**: `/simulation/start` 是 BLOCKING 调用，LLM 跑完才返回 202。测试 monkeypatch `call_with_retry` → `fallback_do_nothing` 绕过真实 API。
- **lru_cache + cache_clear()**: deps.py 的三个 `@lru_cache(maxsize=1)` 工厂函数在 `api_client` fixture 中 `cache_clear()` 隔离，测试间互不干扰。
- **dependency_overrides 未用**: 测试直接用 env var 隔离（INKFISH_DB_URL=tmp_path），更贴近真实运行路径。
